# AOGTrollPlugin

AOGTrollPlugin is a CounterStrikeSharp plugin for CS2 server administrators. It provides 43 effects across seven categories, accessible through an in-game menu. Individual effects can be disabled in the configuration.

[Download latest release](https://github.com/Artemon0/AOGTrollPlugin/releases/latest) · [Release history](changelog.html)

## Quick start

1. Install CounterStrikeSharp, PlayerSettingsCS2 and MenuManagerCS2.
2. Extract the latest plugin release into the plugins directory.
3. Restart the server and configure administrator access.
4. Run `!atroll` in chat.
